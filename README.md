An interactive data visualization project built using Tableau to explore and analyze the distribution, trends, and content metrics of Netflix's catalog across global markets.

📌 Project Overview
This project provides an intuitive visual analysis of Netflix’s movies and TV shows dataset. By analyzing metrics like release years, top-producing countries, content ratings, and genre distributions, this dashboard uncovers key insights into how Netflix expands its content library worldwide.

📊 Key Features & Visualizations
Global Content Distribution: Map visualization showcasing total titles produced by country.

Release Trends over Time: Line/bar charts analyzing content additions and original release years.

Content Breakdown: Categorization by Movies vs. TV Shows, along with total durations and ratings (e.g., TV-MA, PG-13).

Genre & Category Insights: Breakdown of top genres and content ratings across different regions.

🛠️ Tools & Technologies Used
Tableau Desktop / Tableau Public: Data visualization and interactive dashboard design.

Data Source: Netflix Titles dataset (.csv).
